# CLAUDE.md

Las instrucciones de este repositorio están en **[`AGENTS.md`](AGENTS.md)**, que
es la referencia única para cualquier agente. Leelo antes de empezar.

Después, y siempre: **[`docs/ESTADO.md`](docs/ESTADO.md)**. Lleva lo que el
código no puede llevar —dónde está el trabajo, qué se decidió y por qué, qué se
sabe roto, qué trampas ya costaron tiempo— y se actualiza en el mismo commit
que el trabajo que describe.

**Con esos dos alcanza para empezar.** [`docs/HISTORIA.md`](docs/HISTORIA.md)
lleva lo que ya se cerró y **no se lee al arrancar**: se abre cuando aparece la
pregunta «¿por qué esto quedó así?».

No se duplica nada acá a propósito: dos archivos de instrucciones se
desincronizan y aparece la duda de cuál vale.
